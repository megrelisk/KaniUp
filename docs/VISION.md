# KaniUp — იდეის ჩანაწერი (v0)

ClickUp-ის ანალოგი თასქ მენეჯერი RPG / გემიფიკაციის სტილში.

## მოთხოვნები (მომხმარებლის აღწერიდან)

1. **მოწვევა მეილით** — ხალხის დამატება email-ზე გაგზავნილი მოწვევით.
2. **იერარქია:** გალაქტიკა (ყველაზე დიდი) → პლანეტა → თასქი → საბთასქი.
3. **თასქის ველები:** საბთასქები, სირთულე, დედლაინი, პრიორიტეტი, შემსრულებელი(ები), EXP რაოდენობა + სხვა საჭირო ველები.
4. **ფოლდერების (პაპკების) სისტემა** ყველა დონეზე.
5. **როლები:** ადმინი და იუზერები, უფლებების რედაქტირებადი ჩართვა/გამორთვა. როლებს სათამაშო სახელები.
6. **კომენტარები თასქში** — პატარა მესენჯერის სტილში, მოსახერხებლად ხედვადი.
7. **სათამაშო სტილი** — ყველაფერი (UI, ტერმინოლოგია, როლები) RPG-ზე მორგებული.
8. **გარე ინტეგრაციები** — მაგ. თასქის შექმნა Claude-ის ჩატიდან (MCP სერვერი / API).
9. **შეტყობინებები** — email + SMS, როცა თასქი აგვიანებს / დედლაინს გადასცდა.
10. **UI** — სუპერ ინტუიტიური, მარტივად აღსაქმელი.
