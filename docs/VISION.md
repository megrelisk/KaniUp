# KaniUp — პროდუქტის აღწერა და გადაწყვეტილებები

ClickUp-ის ანალოგი თასქ მენეჯერი, კოსმოსურ RPG / გემიფიკაციის სტილში.
**მხოლოდ ჩვენი კომპანიის შიდა პროდუქტი** — ერთი ორგანიზაცია, უფასო, ~100 მომხმარებლამდე.

**სტეკი:** Next.js + React + TypeScript, **Firebase** (Firestore, Auth, Storage). Postgres / Supabase — არა. ჯერ ლოკალურად (Firebase Emulators), მერე ჰოსტინგზე.

---

## 1. იერარქია

```
გალაქტიკა (მიმართულება: მაგ. „მარკეტინგი“, „დეველოპმენტი“)
 └─ მზის სისტემა (ფოლდერი, უსასრულო ჩაშენება)
     └─ პლანეტა (პროექტი: მაგ. „დოქტორიუმის აპლიკაცია“, „კანის საიტი“)
         └─ მზის სისტემა (ფოლდერი პლანეტის შიგნითაც)
             └─ თასქი
                 └─ საბთასქი (საბთასქს საბთასქი აღარ აქვს)
```

- გალაქტიკაზე მაღლა არაფერია.
- ფოლდერი („მზის სისტემა“) შეიძლება იყოს ყველა დონეზე, ფოლდერში ფოლდერი — შეზღუდვის გარეშე. ფოლდერს აქვს სახელი.
- ერთი თასქი ცხოვრობს **მხოლოდ ერთ ადგილას** (ერთ პლანეტაზე).
- დიდი თასქი იშლება საბთასქებად.

## 2. თასქი

| ველი | დეტალი |
|---|---|
| სახელი, აღწერა | აღწერა — rich text |
| სტატუსი | default: **Backlog → To Do → In Progress → In Review → Done**; ადმინი არედაქტირებს და ქმნის ახალს თითოეულ პლანეტაზე |
| სირთულე | Easy / Normal / Hard / Epic / Legendary |
| პრიორიტეტი | Low / Normal / High / Urgent |
| შემსრულებლები | რამდენიმე; XP ნაწილდება პროპორციულად ავტომატურად, ადმინს შეუძლია Review-ს შემდეგ ხელით გადაანაწილოს |
| XP | ავტომატურად ითვლება სირთულე + პრიორიტეტიდან, ადმინს შეუძლია შეცვალოს |
| შექმნის დრო | ავტომატურად (დღე, საათი, წუთი) |
| Time tracking | დახარჯული დროის აღრიცხვა |
| დედლაინი | როდის უნდა შესრულდეს |
| თეგები | ✔ |
| ფაილები | ✔ (სურათები / ფაილების ატვირთვა) |
| Custom fields | ადმინი თვითონ ამატებს ველებს |

**Workflow:** დეველოპერი თასქს გადაიტანს **In Review**-ში („ჩავაბარე“ — ნახევრად შესრულებული საქმე). **In Review → Done მხოლოდ ადმინს შეუძლია** — მაშინ ირიცხება XP.

## 3. ხედები

List · Kanban · Calendar · Gantt/Timeline · **კოსმოსური რუკა** (გალაქტიკა, პლანეტები ორბიტაზე).
**„ჩემი მისიები“ (Home)** — ჩემზე მიბმული ყველა თასქი, ნებისმიერი ხედით.
**ძიება და ფილტრები ყველაფრით:** შექმნის თარიღი, დედლაინი, შემსრულებელი, სირთულე, პრიორიტეტი, სტატუსი, თეგი...

## 4. RPG / გემიფიკაცია

- **XP → ლეველი.** ტიტულები ლეველ 1, 5, 10, 15, 20-ზე (შემდეგ გავზრდით).
- **Achievements / ბეჯები:** streak 3 / 5 / 7 / 30 დღე, „10 თასქი დროზე“ და სხვ.
- **Streak:** ზედიზედ დღეები, როცა მომხმარებელმა თასქი შეასრულა / ჩააბარა (In Review-ში გადაიტანა).
- **ავატარები:** 20 სათამაშო ავატარი (პოლარული დათვი, პინგვინი, ცხოველები, მანქანა...). საკუთარი ფოტოს ატვირთვა არ არის.
- **Leaderboard:** ერთი გუნდი; ჩანს XP, თასქების რაოდენობა და სირთულე (მაგ. ოთომ 50 თასქი, ლადომ 5, მაგრამ 5 Legendary).
- **ხმები და ანიმაციები აუცილებლად:** ლეველის მომატება, თასქის გადატანა, შესრულება — „მონეტის ჩაყრის“ ტიპის ქეშ-ხმები თითქმის ყველა მოქმედებაზე.
- ჯარიმა — **არა**. ვალუტა — **მხოლოდ XP**. Quests — **არა**. გილდიები — **არა**.

## 5. როლები და უფლებები

- როლები სათამაშო სახელებით.
- **ადმინს შეუძლია ახალი როლების შექმნა** და არსებული როლების უფლებების შეცვლა.
- უფლებები **დონეების მიხედვით**: კონკრეტულ ადამიანზე / გალაქტიკაზე / ფოლდერზე / პლანეტაზე.
- ცალკე უფლებები: ნახვა, შექმნა / დამატება, რედაქტირება, წაშლა, მინიჭება, სტატუსის შეცვლა, XP-ის შეცვლა, მოწვევა, კომენტარი.
- **სტუმარი** (მაგ. კლიენტი) — ხედავს მხოლოდ კონკრეტულ პლანეტას.

## 6. მოწვევა და ავტორიზაცია

- მოწვევა მეილით; ადმინი პირდაპირ ირჩევს როლს და გალაქტიკას/პლანეტას.
- მოწვევის ლინკი მოქმედებს **3 დღე**.
- შესვლა: **Magic link (მეილზე ლინკი) + Google**. პაროლი და SMS — არა.
- მრავალი ორგანიზაცია **არ არის**.

## 7. კომენტარები (მესენჯერი)

- თასქის **გვერდითა პანელში**, ჩატის სტილში, real-time.
- @mention, emoji რეაქციები, ფაილები, პასუხი კონკრეტულ კომენტარზე, რედაქტირება/წაშლა.
- სისტემური შეტყობინებები ჩატში: „ნიკამ სტატუსი შეცვალა → Review“.
- გალაქტიკის/გუნდის ზოგადი ჩატი — **არა**.

## 8. შეტყობინებები

- **ვის:** შემსრულებელს, შემქმნელს და ადმინს.
- **როდის:** დედლაინის დღის **დილას** — „დღეს ბოლო დღეა“; თუ გადასცდა — **ყოველ დილას**, სანამ არ დაიხურება.
- **არხები:** email + browser push (+ აპის ზარის ღილაკი). **SMS / Twilio — არა** (მომავალში, საჭიროების შემთხვევაში, ქართული პროვაიდერი).
- სხვა მოვლენები: ახალი თასქის მინიჭება, @mention, კომენტარი, ლეველის მომატება.
- შეტყობინებების პარამეტრებს **მხოლოდ ადმინი** ცვლის.

## 9. ინტეგრაციები

- **MCP სერვერი Claude-ისთვის:** თასქის შექმნა, ნახვა, განახლება, დახურვა, ფილტრით ინფორმაციის მიღება.
- **REST API + API გასაღებები.**
- სხვა (Slack, Telegram, Google Calendar, GitHub, Gmail, Webhooks) — **პირველ ეტაპზე არა**.
- აპის შიგნით AI ასისტენტი — **არა**.

## 10. დიზაინი / UX

- კოსმოსური **sci-fi**, მუქი თემა. **ნეონი არსად!** ძალიან ლამაზი და სუფთა UI.
- ენა: **ქართული + ინგლისური** (გადამრთველით).
- **მუქი / ღია** თემა (გადამრთველით).
- მობილური: ძალიან გამარტივებული, მაგრამ ყველა ფუნქცია ხელმისაწვდომი.
- **Drag & drop ყველგან.**
- Activity log (ვინ რა შეცვალა) — **აუცილებელი**.
- ექსპორტი / CSV / Trello-დან იმპორტი — **არა**.
- გადახდები / გეგმები — **არა**.
